How to Write a Better Prompt

Last reviewed: September 2026 · General educational content, not a substitute for specialized professional advice.

A good prompt does not need to be extremely long. It needs to remove ambiguity. Give the model what it needs to understand the task, then specify what the result should look like.

1. The task

Start with a clear action: summarize, compare, write, analyze, suggest, or rewrite.

2. The context

Explain who you are writing for and why. Example: “Write for an Arabic-language blog aimed at beginners.” This changes the appropriate language and depth.

3. The constraints

Specify length, tone, what to avoid, and whether you want sources or examples. Good constraints reduce generic output.

4. The output format

Ask for a table, bullets, a paragraph, or steps. When you know the format you want, request it explicitly.

5. Review

Use a second pass to improve the result: ask the model to reveal assumptions, check consistency, or reduce repetition. Prompting is an iterative process, not one magical command.
